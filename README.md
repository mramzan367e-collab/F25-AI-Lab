# F25-AI-Lab



Course lab work for Artificial Intelligence Labs 1–4. Each lab folder contains Python source, captured output, and the required DOCX explanation report.



## Requirements

- Python 3.9 or newer
- 
- Standard library only for the lab scripts
- 


## Run

```bash

python3 Lab-1/lab1_compare.py

python3 Lab-1/lab1_rules.py

python3 Lab-2/lab2_percepts.py

python3 Lab-2/lab2_peas.py

python3 Lab-3/lab3_search.py

python3 Lab-4/lab4_astar_audit.py

```



The reports explain assumptions, methods, test cases, observed results, limitations, reflections, and sources. Scholarship thresholds and sample probabilities are synthetic; no model is trained. The classroom controller is simulation-only. Lab 3 documents its equivalent weighted graph.
